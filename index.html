Instrucciones de Configuración

Esta página está lista para publicarse en GitHub Pages y asociarse a tu dominio fmpuebloviejo.com.ar.

1. Cambiar los enlaces de Streaming

Abre este archivo index.html en tu editor y busca al final las etiquetas <audio> para colocar las URLs directas de tus emisoras:

<audio id="mainAudioStream" src="https://s3.netradiofm.com/p/6042/stream"></audio>
<audio id="secondAudioStream" src="https://s3.netradiofm.com/p/5252/stream"></audio>

2. Cambiar Redes Sociales y Teléfono

Busca los enlaces con IDs linkWhatsapp, linkFacebook, etc., y actualiza el atributo href con tus cuentas reales.

3. Subir a GitHub Pages

  1. Crea un repositorio en GitHub (ej: radio-pueblo-viejo).
  2. Sube este archivo renombrado como index.html.
  3. Ve a Settings > Pages en GitHub y selecciona la rama main / root.
  4. En Custom domain ingresa fmpuebloviejo.com.ar.
  5. Configura los DNS de tu dominio apuntando a GitHub Pages (Registros A/CNAME).
